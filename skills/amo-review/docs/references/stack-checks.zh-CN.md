# 技术栈检查

按 SKILL.md 的指引读取相关章节。仅在审查范围内出现对应改动时使用该行；这些是调查方向，不是自动成立的问题，也不要求逐项运行测试。

## Vue / TypeScript

| 改动位置 | 追踪内容 | 报告前核实 |
| :--- | :--- | :--- |
| 组件 props、emits 或 model | 对照参数类型、事件时序、受控状态及每个受影响调用方的监听。 | 更新事件和变更事件可能同时有意存在；须确认消费者丢失状态或重复执行操作。 |
| 筛选、分页、勾选或组件复用 | 追踪路由、账号、数据集变化时的状态归属，以及约定的重置／保留行为。 | 保留状态只有在违反预期范围，或导致结果／操作错误时才是缺陷。 |
| watcher 与请求入口 | 从事件处理、watcher、路由更新追踪到实际请求及界面结果。 | 声称重复执行前，检查批处理、相等判断保护，以及有意区分的请求。 |
| 异步响应与范围切换 | 判断新搜索、导航或关闭后，哪个响应还能更新当前页面或抽屉。 | 请求序号保护可能已阻止旧响应写入；未取消请求本身不证明会展示旧数据。 |
| 定时器、监听器与订阅 | 根据实际场景追踪卸载、停用和重新进入时的注册与清理。 | 区分框架自动管理的清理，以及在组件托管范围之外创建的资源。 |
| API 值与 TypeScript 断言 | 将真实响应结构、可空字段、字符串／数字转换及标识符追踪到比较和操作。 | 类型断言或 any 不是运行时检查，但使用它们本身也不构成缺陷；须确认不兼容的值实际可达。 |
| HTML、URL 或前端权限判断 | 将不可信值追踪到渲染／导航入口，将受保护操作追踪到服务端鉴权。 | 核对转义、净化、URL 校验或服务端保护；界面是否显示既不能证明，也不能实现权限控制。 |

## Python

| 改动位置 | 追踪内容 | 报告前核实 |
| :--- | :--- | :--- |
| 可变默认参数、类属性、全局变量或闭包 | 检查状态是否违背意图，在调用、实例、请求或循环迭代之间保留。 | 只读默认值、有意设计的缓存及局部状态不属于意外共享。 |
| 可选或不完整数据 | 从实际生产方到消费方，追踪空集合、缺失键、None 及单位／类型转换。 | 遵守上游已验证的约束，不臆造边界已排除的输入。 |
| 异常处理或部分完成的工作 | 追踪失败传播、对外成功反馈及已执行的写入。 | 外层处理器可能有意恢复；报告丢失的失败或不一致结果，不报告偏好的 except 写法。 |
| 文件、连接、锁或生成器 | 追踪成功、提前返回、异常及取消时的释放。 | 框架生命周期或完整的 try/finally 清理可以满足要求，不强求 with 写法。 |
| 异步函数与后台任务 | 检查事件循环内的阻塞操作、任务寿命、异常处理和取消清理。 | 核实真实调用环境及执行器／任务管理器；创建任务后未直接 await 不一定有问题。 |
| 并发更新或重复操作 | 追踪共享状态的读改写、事务边界、幂等与重复副作用。 | 确认存在并发或重试调用，检查锁、原子操作或数据库约束。 |
| SQL、shell 命令、反序列化或文件路径 | 沿构造、校验到执行，追踪输入的可信程度。 | 检查参数化及边界保护是否有效；API 名称或可信常量本身不证明可被利用。 |
| 循环、查询或大集合构建 | 将重复 I/O、N+1 访问或内存增长与实际路径、预期数据规模关联。 | 没有实际负载或资源影响时，不报告假设中的性能成本。 |
